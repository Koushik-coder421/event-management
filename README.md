# 🚀 Campus Connect - College Event Management System

Campus Connect is a full-stack web application designed to simplify college event and club management. 
It provides a centralized platform where students, club administrators, and super administrators can manage clubs, events, registrations, and activities efficiently.

## ✨ Features

- Centralized dashboard for college activities
- Portal access for Super Admin and Club Admins
- Student registration using college roll number and details
- Event registration and participation management
- QR-based payment verification workflow
- Fixed payment amount with countdown timer
- Transaction ID submission and payment screenshot upload
- OTP-based email verification after registration
- Club creation and management
- Event creation, updates, and detailed event information
- Role-based access control
